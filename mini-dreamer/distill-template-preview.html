Introduction

The Transformer architecture has become the foundation of modern deep learning for language, vision, and beyond.1 At its core lies the self-attention mechanism, which allows each element in a sequence to attend to every other element, dynamically weighting their contributions based on learned compatibility functions.

1 Vaswani, A. et al. (2017). "Attention Is All You Need." Advances in Neural Information Processing Systems, 30.

Query, Key, and Value

Self-attention operates on three projections of the input: queries, keys, and values.2 Given an input matrix X, we compute Q = XW_Q, K = XW_K, and V = XW_V, then calculate attention weights via:

Attention(Q, K, V) = softmax(QK^T / √d_k) V

2 The scaling factor √d_k prevents the dot products from growing too large in high dimensions, which would push softmax into regions with very small gradients. 
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Compute scaled dot-product attention."""
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / d_k ** 0.5

    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)

    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights

Why Multiple Heads?

A single attention head can only capture one type of relationship at a time.3 Multi-head attention runs several attention functions in parallel, each with its own learned projections, then concatenates and projects their outputs. This allows the model to jointly attend to information from different representation subspaces.

3 Empirically, different heads learn to focus on different linguistic phenomena: syntactic dependencies, coreference, positional patterns, etc. See Clark et al. (2019), "What Does BERT Look At?"
